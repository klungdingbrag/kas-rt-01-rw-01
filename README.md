# Kas RT 01 / RW 01

Aplikasi pencatatan keuangan RT 01 / RW 01, Dukuh Gudang, Desa Surorejan, Kecamatan Puring, Kabupaten Kebumen.

## Arsitektur

- **Frontend:** GitHub Pages (HTML/CSS/JavaScript)
- **Backend:** Google Apps Script Web App
- **Database:** Google Sheets
- **Storage:** Google Drive
- **Reports:** PDF generated by backend

## Status

Frontend awal tersedia dalam **demo mode**. Backend Google Apps Script belum dihubungkan ke URL API.

Untuk menghubungkan backend, edit `js/config.js`:

```js
window.KASRT_CONFIG = {
  appName: 'Kas RT 01 / RW 01',
  apiUrl: 'URL_WEB_APP_GOOGLE_APPS_SCRIPT',
  demoMode: false
};
```

Jangan pernah menaruh password admin, token, atau secret di repository frontend.

## Prinsip keamanan

- Edit transaksi membutuhkan password admin.
- Pembatalan transaksi tidak menghapus histori.
- Perubahan dan pembatalan dicatat dalam audit log.
- Password hanya diproses di backend.
