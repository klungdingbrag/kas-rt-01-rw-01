# Kas RT 01 / RW 01

Aplikasi pencatatan keuangan RT 01 / RW 01, Dukuh Gudang, Desa Surorejan, Kecamatan Puring, Kabupaten Kebumen.

## Arsitektur

- **Frontend:** GitHub Pages (HTML/CSS/JavaScript)
- **Backend:** Google Apps Script Web App
- **Database:** Google Sheets
- **Storage:** Google Drive
- **Reports:** PDF generated by backend

## Struktur

```text
index.html
css/style.css
js/config.js
js/api.js
js/app.js
backend/Code.gs
```

## Setup backend

1. Buka Google Apps Script baru.
2. Salin isi `backend/Code.gs` ke project Apps Script.
3. Pastikan project menggunakan spreadsheet Kas RT yang sudah dibuat. ID spreadsheet saat ini sudah ada di konstanta `DB_ID` pada backend.
4. Jalankan fungsi `setupApp()` satu kali dan berikan seluruh authorization yang diminta Google.
5. Buka **Deploy → New deployment → Web app**.
6. Pilih **Execute as: Me**.
7. Atur akses Web App agar dapat diakses oleh pengguna aplikasi sesuai kebutuhan.
8. Salin URL Web App.
9. Isi URL tersebut pada `js/config.js` dan ubah `demoMode` menjadi `false`.

Contoh:

```js
window.KASRT_CONFIG = {
  appName: 'Kas RT 01 / RW 01',
  apiUrl: 'URL_WEB_APP_GOOGLE_APPS_SCRIPT',
  demoMode: false
};
```

## API

- `GET ?action=health`
- `GET ?action=initialData`
- `GET ?action=transactions`
- `POST action=createTransaction`
- `POST action=updateTransaction`
- `POST action=cancelTransaction`
- `POST action=updateConfig`
- `POST action=changePassword`
- `POST action=exportReport`

## Keamanan

- Password admin tidak disimpan di frontend.
- Password disimpan sebagai SHA-256 hash di Script Properties.
- Edit transaksi membutuhkan password admin dan alasan perubahan.
- Pembatalan transaksi tidak menghapus histori.
- Perubahan dan pembatalan dicatat pada `AUDIT_LOG`.
- Jangan menaruh password, token, atau secret di repository frontend.

## Password awal

Password awal backend adalah `RT01@2026`. **Segera ganti setelah backend berhasil aktif.**

## Catatan CORS

Frontend menggunakan request POST `text/plain` untuk menghindari preflight JSON yang tidak diperlukan. Jika browser masih memblokir request karena kebijakan cross-origin pada deployment tertentu, gunakan URL Web App `/exec` yang benar dan pastikan deployment dapat diakses oleh pengguna frontend.
