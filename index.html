BUKU KAS

Transaksi

Tambah Transaksi

Database adalah sumber kebenaran utama.

Prinsip pencatatan

  • Setiap transaksi memiliki ID unik.
  • Saldo dihitung server dari saldo awal + pemasukan AKTIF − pengeluaran AKTIF.
  • Browser tidak menjadi sumber saldo.
  • Edit tidak menghapus histori.
  • Pembatalan menjadi DIBATALKAN dan tetap tercatat.
  • Perubahan admin masuk audit log.
